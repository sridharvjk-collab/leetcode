# LeetCode Practice – Python

A collection of 29 accepted LeetCode practice solutions, each stored in a separate Python file.

## Structure
Each file is named using the LeetCode problem number and title.

## Usage
Open an individual `.py` file and submit its solution class/method on LeetCode.
Tree and linked-list files include the standard `TreeNode` or `ListNode` helper definition where needed.

> These are independent LeetCode-style solution files, not one combined application.
